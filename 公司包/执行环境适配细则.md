## 一、分层执行模式（2026-11-09 用户拍板建立·货量考核试点 4 轮验证全绿）

> AI 首跑灵活但贵 → PASS 条沉淀成 Playwright spec → 回归无人值守近零成本 → 脚本红回流 AI 定性自愈。
> 落地件：`{paths.执行工具}\pw_layered\`（README=用法正本；helpers=控件配方 v2；ledger.jsonl=台账；diag*=回流诊断工具）。

- **执行前必查 spec 台账（2026-11-11 用户拍板为硬规则）**：每次接执行任务，必须先查 {paths.执行工具}/pw_layered/ledger.jsonl——凡目标 TC 已有 spec 且非 blocked，必须先走 pw_runner.js 脚本回归（零 token）；脚本红=回流 AI 定性（四态之一）。禁跳过 spec 直接 AI 重跑已 PASS 条目（B/C/D 轮教训）。新跑通的 AI 条目收尾时同步沉淀 spec（禁入清单除外）。
- **通道选择（2026-11-09 用户拍板升级：默认无头）**：**AI 执行一律走 cdp_pool 无头实例（{环境.chrome端口.无头AI执行}=9335 优先，全忙自动扩 {环境.chrome端口.runner独占}=9336+，launch=--headless=new）——禁止默认占用 {环境.chrome端口.用户交互主实例}=9333/{环境.chrome端口.辅助}=9334 有头实例**（用户交互主实例=红线，仅限用户要求现场演示/人工坎时短暂借用）；已 PASS 稳定条＝脚本回归 `node pw_runner.js --specs …`（runner **独占取实例**：9336+ 优先、避开无头池，持锁+每条心跳续锁+全页签业务路由占用检测，他人持锁端口拒用，结束解锁——多会话共用实例会租户互切、结果互相污染，坑库 G36）。无头实例登录态过期→{环境.登录技能} 脚本自动账密重登，机器过不去的坎才停叫人。
- **沉淀准入禁入清单**（拍板#4）：坐标定位条 / any 降级断言条 / 判重造撞类条——永久留 AI 通道，不沉淀。
- **四态**（拍板#3）：通过/待复核/阻塞/不通过——**脚本红只记「待复核」**，必经 AI 回流定性（diag 诊断 → 改版=自愈修 spec → 真缺陷=转 usecase-feedback-loop），禁直接判不通过。
- **造数自清双向 + 只清自己造的**（拍板#4；2026-11-09 拍板库内历史 TEST_ 数据保留）：spec 点「确定」前 `recordCreated` 登记名称台账 → 跑前/跑后 `cleanupOwn` 按台账名称逐条精确删（查询前先点「重置」防条件残留污染）；**禁止 spec 按前缀模糊删**（会误伤同命名格式的历史/他人数据），`deleteByPrefix` 仅留诊断用且带数量闸；沉淀 spec 一律声明 dataPrefix。
- **preflight 设计掉跑错租户/登录过期**：spec 声明 tenant → runner 自动查/切（changeTenant API）；登录过期自动账密重登，机器过不去的坎（人脸/验证码）才停下叫人，不带病跑。
- 回归窗口内执行实例独占；沉淀定位一律走 helpers 配方（2026-11-09 实测页面结构），**勿照抄 11-06 旧 exec_*.js 选择器**（已部分腐烂）。

## 三、开工收尾双闸细则（原 executor 1.86/6.9 细则）

- **开工第 0 步=验上轮收尾（硬闸·2026-11-13 用户质询"有标识吗？靠 memory 有用吗"后立）**：开工先跑两个校验器，任一红=先补上轮收尾再开新轮，禁带病开跑：
  - `python {paths.执行工具}/report_sync.py <账本> <报告.md> 待验`——四重校验：①账本/报告文件时间戳（账本新=上轮执行后报告未同步）②报告头部「最后收尾」声明行 vs 账本最新落账日（声明落后=有未收尾轮）③数字+结构④回写台账 pending 残留=红（台账在账本同目录或{需求}分章\ 下）。
  - `python {paths.执行工具}/writeback_check.py <账本> <用例正本.md> <分章目录> <writeback_pending.jsonl> <测试报告.md> [--defer-artifacts]`——回写完成性六重校验：①pending 残留=红②账本"已回写"字样 vs 台账漏登提醒③统计块=实文 TC 计数④正本/分章失效标注一致⑤附载体锚点（挂起重出期 --defer-artifacts 豁免）⑥附B 完成性声明可追溯台账。
  - 此闸不依赖 memory/自觉——时间戳/声明行/锚点值/文件计数是客观信号（教训=11-12~13 三轮规范在仍漏更，软约束证伪；11-13 账本标"已回写"但文件没改）。
- **收尾客观标识=重跑 report_sync.py 全绿（exit 0）**；汇报附"本轮报告已更新：vN §X＋最后收尾行"自证行。
- **效率指标**：`python {paths.执行工具}/metrics_summary.py <账本jsonl…> --planned <计划条数>`——治理标准§8 指标自动出（状态分布/BLOCKED率/P0123分层/通道效率/覆盖率/轮次耗时段，禁手写），结果路径登记进报告工件索引。
