## 四、统一处理链路（所有计费/重算/取消/修正用例公共骨架）

事件到达（任意事件/人工重算）→ 查仓链（订单维度查订单表、运单维度查运单数据）→ **规则配置门槛**（客户特定结算规则：是否月结、订单/运单维度）→ 匹配报价（生成/更新账单：变化/无变化/对冲清空）→ 结算对应变化（**已实时结算费用金额变化→红冲重结**；未结算业务费只更新金额；月结周期日到达且出库完成→周期结算）。

- 节点裁剪：订单处理节点→只业务仓支出侧；出库完成节点→两侧；已取消→无费用、金额保持空。
- 运单维度**各票独立**：该票出库完成即更新该票行、操作仓收入费用此刻生成、月结按票判。
- 拦截事件重放：重算按当前节点组装全事件链重放，拦截费照算、已对冲保持对冲。

## 五、判定规则表（前置/预期直接引用）

### 5.1 金额四态
| 形态 | 触发 | 可点击 |
|---|---|---|
| 空白 | 无有效报价五态（未维护/未审核/驳回/未生效/已失效）、对冲后、重算失配、无权限 | ❌ |
| 主题色加粗 | 报价命中（**含 0 元**） | ✅ 弹适用报价窗 |
| 黑色 | 有金额无适用报价（合计等） | ❌ 无响应 |

易混三定：对冲后=空不是 0；0 元=有报价可点；合计=有金额永不可点。

### 5.2 三重量
- 理论重量=订单信息结算重量（源字段呈现）；**结算重量=唯一计费重量**：无三方取订单结算重量、有三方无条件覆盖（不论大小）、三方清空回落现值；无三方时活跟随订单结算重量。
- 四条腿（2 元/kg 例）：t1 订单 10→费 20；t2 订单 10→12 三方空→结算 12、费 24；t3 三方 15 到→结算 15、费 30；t4 三方在场订单 12→13→理论列 13、结算 15 不动、费 30 不动。
- **订单总重量=独立维护字段**，管理费不随重量修正变化。

### 5.3 行粒度与时间
| 维度 | 行 | 业务时间 | 出库时间 | 出库完成判定 | 运单状态列 |
|---|---|---|---|---|---|
| 订单 | 1 单 1 行（运单号空） | 最早（min 语义、取仓链当前值） | 正常票最晚 | 正常票全部出库 | **取仓链订单状态**（不自行聚合） |
| 运单 | 1 票 1 行（订单字段重复） | 该票最早处理时间 | 该票自己 | 该票独立 | 该票运单状态 |

### 5.4 月结与取消
- 非月结客户：全实时，现结、月结日期空；**平台费恒实时结算**（不论客户月结与否）。
- 月结客户：业务费待「周期日到达 **且 出库完成**」；未出库顺延下一周期、月结日期同步更新。
- **入库类型**：不在月结配置→实时结算（现结、月结日期空、出库时间列空）。~~本条按 F23 修正~~ → **F23（v1.5，2026-11-02）**：事件五种各自单一（订单处理+出库完成一组仅 B2B/B2C；入库完成仅入库类型=完结状态无出库时间；存储；库内拦截；快递拦截）；**入库费/卸车费只产生于入库类型订单**（B2B/B2C 无入库完成事件）；月结闸门=费用项自身事件完结——**月结客户入库单=入库完成即完结、周期日照结（未月结→已月结、月结日期生成）**，非月结客户实时现结；拦截匹配与出库完成无关（未出库订单拦截费照常产生）；并存断言=同客户同期"入库单已结/出库单挂账顺延"两单并存。
- 已取消（整单/整票）：行留存、费用对冲空、月结状态/日期**保持取消时刻值**、不参与月结推算、可导出可重算（金额保持空）。
- **部分取消**：月结对象=正常运单（已取消票不参与不阻塞闸门、出库时间=正常票最晚）；运单维度同单两行月结状态可不同。

### 5.5 重算三分支（费用项级判定）
| 费用项 | 状态 | 金额变更时 |
|---|---|---|
| 平台费（流量+业务管理） | 恒已实时结算 | **红冲重结** |
| 业务费·现结客户 | 已实时结算 | 红冲重结 |
| 业务费·月结客户未月结 | 未结算 | 只更新金额 |
| 业务费·月结客户已月结 | 已周期结算 | 红冲重结 |

核心场景：同一未月结账单重算平台费+业务费→**两种行为并存**。重算不改变月结状态。跨模块不联动重算。批处理逐单独立。金额不变→无红冲无新交易。

### 5.6 数据权限
- 行过滤 **OR**：业务仓或操作仓∈登录机构及其下级→整行可见；总部见全部。
- 行级金额：该行业务仓∈链→业务仓支出金额可见；操作仓∈链→操作仓两模块金额可见；无权限侧**列在、金额格空**。
- **模块列=结果集级动态判定**：结果集含本侧行→该侧模块列展示；全无→列整体不展示；翻页不变；换条件重查**随新结果集重算**；**空结果集（0 行）只展示订单信息模块（普适含总部）**；总部有数据恒全模块。
- 重算操作权限：仅总部（顶级唯一机构）；非总部=按钮权限配置可见+点击拦截提示。客户维度不参与账单权限。
- **越权路径清单（v1.1，独立定稿 §14 源四）**：列表默认过滤 / **精确单号直查（权限外单号不返回）** / 导出 / 接口直调 / 详情直链——每条路径一条"权限外不可达"；查询/重算/导出三按钮均纳入角色权限配置项（原文"按钮做成权限可配置"，观察类）。
- **动态列兜底形态（v1.3，2026-11-02 冲突①归一，理解说明 F20——"用动态判定设计用例，用全展示兜底"）**：主形态=结果集级动态判定；兜底形态=表头恒全可见（**不判缺陷**，须满足列头完整+无权限金额格空+导出同形态）；**任一形态硬断言=无权限侧金额格零数值**；空结果集两形态均合法（仅订单信息 或 全表头无数据行）。单侧裁剪/空结果集/换条件重查/导出列集类断言一律写**双形态记录式**（形态A 动态裁剪/形态B 全展示兜底，均合法、记录实际形态）。

### 5.7 适用报价弹窗
恒单行（只展示命中报价，平局取编码最新）；菜单列=费用项固定映射（见 §二）；详情=账单侧弹窗展示报价基本信息+**命中的那条价格明细**；快照一致（重算后弹窗=新命中报价）；**操作费两明细（v1.4，F21）**：一个报价、详情价格明细两条（一级/二级单位各一条）、范围段一条、金额合并一笔主题色可点。

### 5.8 导出
异步两步（点导出→「导出任务」菜单下载）；文件=**任务提交时**结果集；导出列=界面动态列（不含勾选框/序号、无权限金额格空）；空结果=**生成空文件**；已取消行随导出；单号互斥同步生效。

### 5.9 操作时序对矩阵（v1.1，独立定稿 §14 源四；有金额账本必做）

重算 / 取消 / 重量修正 / 出库完成 两两 × **双向先后**，断言"后操作以前操作结果为基准"：
| 先 → 后 | 断言 |
| --- | --- |
| 重算 → 取消 | 对冲流水金额=**重算后金额**（非原始金额），账单金额空 |
| 取消 → 重算 | 金额保持空（已取消节点无费用，转测校准⑩） |
| 重量修正 → 取消 | 对冲最新（修正后）金额 |
| 取消 → 重量修正/出库 | 金额保持空、状态保持 |
| 重算 → 出库完成 | 出库事件按最新订单信息重匹配，重算结果不"锁死" |
| 出库完成 → 重算 | 两侧均重算（节点=出库完成） |

## 六、断言锚点口径（云仓账单域）

| 断言对象 | 标准句式 |
|---|---|
| 结算交易（手动重算） | 结算交易记录展示**对冲交易+新金额交易**；创建人=重算操作人；**交易时间不作断言**（账单→结算异步） |
| 结算交易（事件驱动） | 同上两条交易展示；创建人取值=转测校准 |
| 仓事件 | 仓事件菜单生成对应重算事件，**创建时间=重算时间** |
| 弹窗 | 恒单行；详情仅展示命中的那条价格明细（4 段报价命中第 3 段场景） |
| 导出 | 两步断言：任务生成→下载文件内容/列=提交时查询结果 |
| 提示 | 提交重算后界面出现"操作成功"类提示（**有提示即可，文案不作断言**） |
| 金额态 | 按四态判定的样式断言（主题色加粗可点/黑色/空白） |
| 权限 | 列展示/裁剪按结果集判定；金额格空；拦截提示 |

> 通用写法六条（G1~G6）已上收《独立定稿》v1.8 §13；账单/交易断言映射锚点=《独立定稿》v1.8 §7.5 **云仓账单行**（红冲流水+新额结算流水双交易断言、手动重算创建人=操作人、交易时间不作断言）——本文 §六 为账单域落地形态；原标准包内《功能按钮逻辑标准参考》不再被引用。

## 七、转测校准清单（**不得写成肯定式断言**，用"转测校准：观察…"句式）

①结算重量=0 的计费处理（按合法值照常计费理解）；②弹窗"菜单"列实际展示形态（仅菜单名 vs 带页签后缀）；③时间范围边界闭/开区间；④订单号+运单号同填的互斥归属；⑤无效组合重算（如操作仓支出+操作费）提示形态；⑥部分取消时仓链订单状态实际取值；⑦分页档位/单页最大条数实际值（重算上限=单页最大条数）；⑧事件驱动自动更新产生交易的创建人取值；⑨已月结后月结日期列展示形态；⑩已取消单重算金额保持空的推演验证。
