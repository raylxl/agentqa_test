## 一、固定枚举与控件常量（禁止自造取值）

> **归属边界（2026-11-11）**：单仓判据唯一正本为 L3《云仓租户用例编写标准》§2.8；本域原有简写保留为历史来源，不独立定义空值、审核状态或业务时间规则，执行前按现行需求理解说明核对。金额可点击通用规则见 L2《账单族标准》，此处仅保留存储账单的维度、明细/汇总和存储费专属结果。仓内存储报价来源规则引用对应来源菜单资产；本域持有账单侧呈现和数据断言。

| 项 | 常量 |
|---|---|
| 页签 | 双页签：汇总账单（默认）/ 明细账单 |
| 单号框（两页签同款） | 多行文本+**维度下拉**：汇总页维度=结算单号（单型）；明细页维度=结算单号/托盘号双型切换（选"结算单号"填托盘号=无数据、混填只命中选中型）；一行一个；任一单号填写即**互斥**（其它条件后端忽略、前端不清空）；多单号 OR；trim 空格、忽略空行；行数无上限（N+N+1 探测定界） |
| 日期控件 | 汇总页="存储日期"、明细页="日期"（同字段=统计存储费的理论日期）；年月日；范围**最大 1 年**；闭区间（转测校准） |
| 下拉 | 客户/业务仓/操作仓=单选模糊匹配 contains 不分大小写；月结状态=单选 现结/未月结/已月结（仅汇总页有） |
| 列表勾选框（明细页/汇总页同款） | **导出范围选择器**：未勾选=按查询条件导出；勾选=仅导出勾选行；勾选仅当前页、翻页清空；汇总页勾选兼作重算行选择器（**双重用途，2026-11-03 用户拍板**，修订原"汇总页仅重算用"） |
| 重算弹窗 | 费用名称（多选必填，**仅"存储费"一值**）+ 账单模块（多选必填，仅"业务仓支出/操作仓收入"两值）；选两模块=两向都重算（各自独立报价） |
| 重算按钮 | 未勾选行**置灰**；勾选（仅当前页）激活；**无二次确认**；提交后"操作成功"类提示（只断言有提示） |
| 重置按钮 | 存在；=条件恢复默认+**自动查询**+**每页条数保留**+**页码回第 1 页**（全系统统一） |
| 排序 | 默认：日期倒序→同日客户倒序→第三键结算单号倒序（第三键转测校准） |
| 菜单路径 | 统一写"进入「财务→存储账单」菜单"（实际路径以环境为准，PRE-01 核对） |

## 二、费用项 × 模块 × 特殊规则常量表（本菜单唯一费用项）

| 项 | 常量 |
|---|---|
| 费用项 | 存储费（唯一） |
| 模块落点 | **同行两列**：业务仓支出（①总部收业务仓）/ 操作仓收入（②总部付操作仓）——非云仓账单的三模块结构，禁搬 |
| 报价来源 | 仓内作业价格-存储页签（托盘形态/重量形态两类报价） |
| 弹窗"菜单"列 | **仓内作业价格-存储**（菜单-页签模式，费用项归属页签后缀） |

**上游（仓内作业价格-存储）特殊规则 → 本账单呈现映射**：

| 上游规则 | 账单呈现 | 现行出处 |
|---|---|---|
| 温层必填五值精确匹配硬过滤（冷冻/冷藏/常温/保鲜/其他） | 报价温层≠事件温层→整报价不命中→无费用行 | 仓内 #G / 需求文档 §3.2 |
| 优先级 客户>业务仓>操作仓、精确值>空 | 匹配唯一报价（重复校验保证）；不命中双断言 | 需求文档 §3.2 |
| 段边界左开右闭 0<值≤段结束 | 天数/重量均按此落段；边界值=段结束值落本段、段结束+0.01 落下段 | R5 |
| 单仓不产生（同仓 OR 税号均非空且相等、按业务时间查已审核税务记录；**空税号不算一致、未审核不参与判定**，完整七要素唯一正本=L3《云仓租户用例编写标准》§2.8·2026-11-11 拍板C） | **行照常生成、两金额格空白**（汇总与明细对称） | #A1/#B + Q5/C5 |
| 0 值不落段（0 不>0） | 金额空白 + 结算交易记录无记录（非 0.00） | R2 + U1 修订 / C2 |
| 越界（>最后段结束值）不匹配不计费 | 天数越界/重量越界均金额空白 | R9 + C9 |
| 最低/最高收费钳位（重量形态） | max(最低, min(最高, 段单价×组总重)) | R9 |
| 双向独立报价、金额可不同 | 两列金额独立断言；重算模块两值 | #H |
| 精度：两位四舍五入、舍入在明细加总之后 | 精度条账单+结算交易记录双锚点 | #F |

## 三、列结构常量

- **汇总账单 17 列 + 勾选框**（列序）：勾选框、序号、结算单号、日期、客户、业务仓、操作仓、业务仓支出、操作仓收入、月结状态、月结日期、业务省公司、操作省公司、托盘数量、重量（kg）、存储温层、创建人、创建时间。
- **明细账单 17 列 + 勾选框**：勾选框、序号、结算单号、托盘号、日期、客户、业务仓、操作仓、业务仓支出、操作仓收入、业务省公司、操作省公司、入库日期、存储天数、重量（kg）、存储温层、创建人、创建时间（无月结状态/月结日期）。
- 入库日期=订单托盘信息 list 该托入库日期，**年月日格式**；存储天数=在库总天数（含入库当天）；重量=托盘货物重量（明细）/组总重（汇总，重量形态与计费同源）。
- 创建人默认"系统"，重算时=当前操作人（创建时间是否刷新=转测校准）。

## 四、统一处理链路（所有计费/对冲/重算用例公共骨架）

事件到达（每日存储事件 / 取消事件 / 人工重算）→ 查仓链订单数据（托盘信息 list：天数字段、重量、入库日期、业务仓归属、温层——**订单里是什么按什么算**）→ 匹配报价（**事件时间锚点**、温层硬过滤、优先级、跨期自动切换）→ 计费（托盘=逐托落段 Σ；重量=组总重落段+钳位）→ 结算对应变化（取消→对冲；已实时/已月结金额变→红冲重结；未月结→只更新；周期日→周期结算）。

- 生成时点：每日 23:50 跑批、T 日账单 T 日生成；账单"日期"=事件时间（只展示年月日）。
- 事件序列三合法形态：存储-存储（持续）/ 存储-取消（订单级对冲）/ 存储-取消-再入库（重新计费）。

## 五、判定规则表

### 5.1 金额呈现 2×2 与空白五态
| 计费维度 | 汇总账单 | 明细账单 |
|---|---|---|
| 托盘 | Σ各托（可对应多报价）→**黑色不可点** | 每托一行各自报价→**主题色加粗可点**（弹适用报价） |
| 重量 | 组总重唯一报价→**主题色可点** | **金额不展示（空白）**，重量列照常 |

金额空白五格：无有效报价五态（未维护/未审核/驳回/未生效/已失效）/ 单仓 / 重算失配 / 0 值 / 取消对冲。含 0 元报价命中=主题色可点（0 元≠空白）。

### 5.2 计费公式
- 托盘：第 N 天金额=Σ每托(天数字段 N→落天数段→段单价×1托)；逐托定段（天数字段仓链直给）；当日一笔每天收一次；跨段日单价跳变可断言；天数含入库当天（09-01→09-28=28 天）。
- 重量：第 N 天金额=max(最低收费, min(最高收费, 落段单价×组内托盘总重量))；**组总重落段**（单托重量不参与落段）；日租金不乘天数；计费/展示重量=订单托盘重量字段。
- 出账分组：**天+客户+操作仓+温层** → 结算单号；业务仓列=客户绑定仓带出（1 客户:1 业务仓、1 仓:N 客户）。

### 5.3 行粒度
汇总=一分组一行（托盘数量/重量=组合计）；明细=**每托每天一行**（挂所属结算单号）。

### 5.4 事件模型与取消（核心拍板）
- 日事件：货在库=发当天存储事件=计 1 笔；统计时不在库=无事件无费用（出库日无单、无出库概念）。
- 取消：**订单级**（一取消事件消息→整单全托取消，无单托取消逻辑）；**逐日事件对应**（每个取消事件只冲对应那一天的费用、多天=多事件一一对应）；已产生费用**全额对冲**（账单金额空白+结算交易记录"已对冲"、对冲额=原额）；无拦截事件。
- 对冲落账：逐日逐单——托盘形态 Σ 中移除该订单各托；重量形态组总重扣减后**重新落段**（可能跨段变价）；已月结/已现结单=冲回式对冲。
- 再入库：按新事件流重新计费（新入库日期、天数按仓链给值）。
- 重复事件幂等；迟到事件按事件时间生成历史日期账单。

### 5.5 重算（全平移云仓账单机制）
| 项 | 口径 |
|---|---|
| 取数 | 调仓链/WMS 取最新托盘数据（天数、重量、业务仓归属） |
| 匹配 | 按每天存储事件（事件时间）逐日重匹配**重算时点**有效报价（历史日单可追溯改价） |
| 金额变更 | 现结/已月结=红冲重结（两条流水）；**未月结只更新不结算**（账单模块无平台费特例、按整单状态三值分流） |
| 状态 | 重算不改变月结状态；报价失配→金额变空 |
| 对冲单重算 | 可重算→按最新事件流（含取消）→**金额保持空白** |
| 颗粒度 | 结算单维度（汇总页勾选）；关联明细一并更新；**重算=修正非生成——重算后断言无新日期结算单号产生（反向排除，2026-11-02 WB 对比回写）** |
| 批量 | 逐单独立、部分失败不影响他单 |
| 反馈 | 异步（同导出任务模式）；有提示 |

### 5.6 月结
- 是否月结+周期日=**客户特定结算规则配置**；非月结客户=现结（生成时即结算、月结日期空）。
- 月结客户：**周期日即结**（与出库无关、无顺延）；周期日凌晨作业结算当期累计；月结日期预计=下一周期日/实际=真正结算日；入库完成=订单完结状态（无出库闸门）。

### 5.7 数据权限
- 行过滤 OR：业务仓或操作仓∈登录机构及下级→整行可见；总部见全部。
- 列级：业务仓及其上级→可见"业务仓支出"；操作仓及其上级→可见"操作仓收入"；无权限侧**金额格空**（乙主甲兜两模式转测校准）。
- 重算仅总部：非总部按钮可见+点击拦截（三层模型）；查询/导出/重算按钮均权限可配置（观察类）。
- 越权路径七线：列表默认过滤 / 结算单号直查 / 托盘号直查 / 条件交集 / 导出 / 接口直调 / 弹窗详情直链。**接口直调线按操作类型展开**（2026-11-02 WB 对比回写）：查询接口与重算提交接口（本菜单唯一写操作）各出一条"非授权 token 直调被拦"。

### 5.8 适用报价弹窗
列=菜单/报价编码/报价ID/报价名称/生效区间/费用名称/结算流向/操作；「详情」=报价基础信息+价格明细**仅命中一条**（多明细只展示命中行）；菜单列=仓内作业价格-存储；重算后弹窗=新命中报价（快照一致）。

### 5.9 导出
- 汇总页：按查询条件；导出信息与页面展示一致（动态列同展示）。
- 明细页：勾选框=范围选择器（未勾=查询条件、勾=勾选行）。
- 异步两步（任务生成→下载）；空结果=仅表头空文件；不含勾选框/序号列。

### 5.10 操作时序对矩阵（BRIEF 已逐格派章，此处为口径）
重算→取消=对冲以重算后金额为准；取消→重算=保持空白；取消→再入库=重新计费；报价变更→重算=按重算时点新价；重量修正/转温→重算=按最新数据；重算→新事件=不锁死。

## 六、断言锚点口径（存储账单域）

| 断言对象 | 标准句式 |
|---|---|
| 结算交易（重算红冲） | 结算交易记录=对冲交易+新金额交易双流水；创建人=操作人；交易时间不作断言 |
| 结算交易（取消对冲） | 结算交易记录展示"已对冲"、对冲额=该订单该日原额（逐日逐单） |
| 精度 | 账单金额与结算交易记录金额**双锚点**、均含完整算式 |
| 提示 | 有提示信息即可（文案不断言） |
| 金额态 | 按五态+2×2 的样式断言（主题色可点/黑色/空白） |
| 权限 | 金额格空/列动态/拦截提示 |

## 七、转测校准清单（禁肯定式断言，用"转测校准：观察XX"）

①排序第三键（结算单号倒序）实际实现；②非总部无权限模块列形态（乙动态列 vs 甲恒全列+金额空）；③23:50 跑批确切时刻；④订单取消对冲后行内"托盘数量"列是否扣减；⑤重算后创建时间是否刷新为重算时间；⑥存储日期范围边界闭/开区间；⑦单号多行框行数上限（按无上限 N+N+1 设计）；⑧分页档位/单页最大条数（重算上限）；⑨事件驱动（对冲/自动更新）交易的创建人取值；⑩明细页"日期"条件与账单日期字段确认同源。

## 八、数据准备（PRE）依赖清单（非用例、不计条）

| 类 | 需备数据 |
|---|---|
| 客户特定结算规则 | 非月结客户（现结）；月结客户（周期日可设定，如 15 日） |
| 机构与税号 | 总部账号；省公司（下辖业务仓+操作仓）；业务仓账号；操作仓账号；单仓=同仓或税号一致（最新版已审核、按业务时间）；非单仓=税号不同/单空/双空 |
| 报价 | 存储页签两类：托盘天数段（含多段、末段截止值有限场景）+ 重量段（含最低/最高收费）；①总部收业务仓②总部付操作仓两向各一套；五态（未维护/未审核/驳回/未生效/已失效）；0 元价；跨期两连报价（生效区间衔接） |
| 事件序列 | 持续存储多日、订单级取消（多日多取消事件）、取消后再入库、转温层、客户换绑业务仓、托盘重量修正、迟到补推、同日重复推送 |
| 对照组 | 单仓行 vs 非单仓行；现结 vs 月结客户；两形态报价命中对照 |
