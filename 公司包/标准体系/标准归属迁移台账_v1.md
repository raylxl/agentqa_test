# 标准归属迁移台账 v1（2026-11-11）

> 用途：记录标准体系归属纠偏；本台账不替代各层内容正本。迁移纪律：**搬正本不删知识**。历史原文、拍板、示例、来源和差异均须在目标正本或原文件“历史迁移保全附录”留存；原位置的现行段落改为指向唯一正本。未获业务拍板的冲突仅登记，不静默裁决。

## 一、归属原则

| 层 | 唯一职责 |
|---|---|
| L0 | 测试角色、全谱系和置信度姿态 |
| L1 | 跨族/租户经典设计方法定义、方法选择、覆盖证明、通用断言与设计红线 |
| L2 | 业务族机制与专门化规则（报价政策、账单、计费） |
| L3 | 单一租户跨多个需求一致的业务口径 |
| L4 | 单一菜单/需求域事实、常量、公式、字段与局部规则 |
| L5 | 风险策略、阶段治理、设计/执行/发布门禁、交付格式 |
| L6 | 执行集消费、动作/断言编译、数据注入、运行证据、结果判定、反馈闭环 |
| L7 | 对外分发派生标准，不作为内部正本 |
