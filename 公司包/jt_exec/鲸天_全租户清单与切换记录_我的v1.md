## 观察要点

- **tenantType**：冷链快运=2（主租户，独有 domain=jt-ll 本域），其余=1。
- **当前租户判定**：下拉内租户看 `.tenant-item` 带 `.selected-icon`；直接显示的租户（冷链快运/网络货运/项目管理/财务中台）看 `.tenant-item.active`；冷链快运的签名是顶级菜单数 32。
- **空租户**：客户服务平台(48)、物料商城(46) 切换 API 成功但菜单为空（首页外无内容），页面头部也不显示，与旧文档"可能需要特殊权限"一致。
- **冷链智运(77)** 菜单最多（36，含 08191、栏目菜单重复测试等测试栏目），且租户自带独立 domain（zhiyun.test.ztoeco.com），在 jt-ll 内切换仍可用。
- **财务中台(78)** 的 tenantCode 是 "99"（异常值，非 T 前缀格式），调用时以 tenantId 为准。
- 全程 SSO 会话共用，8 次切换+1 次回切均未触发重新登录；旧页签刷新后会变成新租户（localStorage 菜单全页签共享）。

## 切换机制（有效口径）

```
POST http://gateway-ll.test.ztoeco.com/uas/auth/changeTenant
headers: Authorization/authtoken = localStorage.MICRO_APP_MAIN_TOKEN_KEY（jt-ll 域）
         PlatformCode: ZTOCC_PLATFORM_001
         client-Type: pc
body:    { "platformCode": "ZTOCC_PLATFORM_001", "tenantId": <id> }
→ 200 + data.token（新租户 JWT；本版本无 refreshUrl）
→ localStorage.MICRO_APP_MAIN_TOKEN_KEY = 新token
→ 删 MICRO_APP_MAIN_MENU_LIST / MICRO_APP_MAIN_MICRO_ROUTES（清租户菜单缓存）
→ location.href = http://jt-ll.test.ztoeco.com/dashboard
```

⚠️ 下拉 UI 点击法（点 `.el-dropdown-menu__item`）2026-10-27 实测已失效：无弹窗、无接口调用、无跳转；真实坐标点击同样无效。不要再用 UI 法排障。
