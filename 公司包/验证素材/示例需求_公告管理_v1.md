# 示例需求：运营后台「公告管理」配置化改造（验证用）

> 来源：WorkBuddy 技能触发验证件（2026-11-16 造，中性示例，非真实需求）

## 背景

运营后台现有公告为开发写死，运营要求改为可配置：按人群定向发布、可定时上下线、支持撤回。

## 功能点

1. **公告列表**：新菜单「公告管理」，列表字段=标题/类型/状态（草稿、生效中、已下线）/生效时段/创建人/创建时间；支持按类型与状态筛选。
2. **新增公告**：字段=标题（≤50 字必填）、类型（活动/维护/政策三选一）、正文（富文本≤5000 字）、生效起止时间（起<止）、定向人群（全量/指定用户组多选）。
3. **定时上下线**：到达生效起始时间自动上线，到期自动下线；允许手动提前下线。
4. **撤回**：已上线公告可撤回，撤回后进入「已下线」，不可再上线（只能复制新建）。
5. **置顶**：同类型公告可置顶一条，新置顶自动取消旧置顶。

## 非功能

- 列表加载 ≤2s（公告量级 ≤1 万条）；
- 正文富文本需过滤脚本注入；
- 操作留痕：新增/上下线/撤回/置顶全部记录操作人与时间。

## 边界与疑问点（待确认）

- 生效时间跨天公告，当天 0 点是否算"进行中"？
- 撤回后同标题能否立即新建？
- 定向人群与用户组服务的关系（实时取还是快照）？
