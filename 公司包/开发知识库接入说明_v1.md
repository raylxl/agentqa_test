# 开发知识库接入说明（同事版 v1，2026-11-17 立）

> 作用：agent 的"开发知识库"（integrations.knowledge_base，weknora 服务）供技能在需求考古、背景查证时**检索知识卡**（需求说明/决策记录/接口文档等）。默认配置已可用，换库/换环境按本文操作。

## 一、它在哪

| 层 | 位置 |
| --- | --- |
| 配置登记 | `公司包/agent-company.json` → `integrations.knowledge_base`（`url`=服务地址、`adapter`=适配器路径） |
| 适配器 | `公司包/tools/wk_kb.py`（公司层直连，不走用户级 MCP 挂载） |
| 凭证（可选） | `公司包/agent-secrets.json` → `weknora.token`（Bearer；**缺省裸调实测可用**，服务无状态） |
| 默认知识库 | `ztocc-knowledge-docs`（公司开发库；kb_id 在适配器默认值） |

## 二、三种情况

1. **同公司直接用（零配置）**：包内默认 url（`http://10.204.11.251:8082/mcp`）+默认库，开箱即用；若服务要求鉴权再把 token 填进 `agent-secrets.json` 的 `weknora.token`。
2. **换知识库（别的库/别的内容源）**：改 `agent-company.json` → `integrations.knowledge_base.url`；库 id 不同则按适配器内 kb_id 参数传（`raw` 命令可指定）。
3. **换环境（如知识库部署地址变了）**：只改 `url` 字段，其他不动。

## 三、用法（三条命令）

```bash
python 公司包/tools/wk_kb.py search "报价优先级"        # 检索知识卡并按文档汇总
python 公司包/tools/wk_kb.py chunks <knowledge_id>      # 取指定文档正文块
python 公司包/tools/wk_kb.py raw <tool名> '<json参数>'   # 任意 MCP tool 原样调用（诊断）
```

## 四、纪律与坑

- **知识卡只作参考，永不替代拍板**——卡片内容 ≠ 现行口径，冲突时以需求文档/用户拍板为准；
- 禁用 Git Bash curl 直调服务（中文 GBK 坑），必须走本适配器（Python UTF-8）；
- 返回是 SSE 流（取 `data:` 行）；大卡正文块可能分页；个别卡 parse_status=failed 但检索块仍可用。

## 五、不接会怎样

不配知识库，agent 主链（设计/执行/报告）完全不受影响；只是需求考古六源里少一源，背景查证降级为"问人/看代码库"（代码库接入见《开发代码库接入说明_v1.md》）。属增强项，非必选项。
