# 域层起步指引（公司层包 · 各产品线同事必读）

> 你拿到的是：**公开层方法论**（标准+模板+机检+十技能）+ **公司层**（鲸天环境登录技能+执行框架 jt_exec+本指引）。
> 你还没有的是：**域层**——你的产品线（经营/运输/品控/平台/财务…）的用例库、台账、域标准、需求文档。
> **域层不随包分发，由你跑流水线自己生成**（下面四步，约半小时起步）。

## 三层一图

```
公开层（任何人）＝方法论：怎么答疑、怎么设计用例、怎么质疑、怎么出报告
公司层（本公司）＝环境与工具：怎么登录鲸天、怎么切租户、怎么跑执行框架
域层（你的产品线）＝你的数据：你的需求文档、你的用例库、你的台账、你的域标准
```

## 第一步：部署（10 分钟，见包内《部署说明》）

装 ZCode 客户端 + Python(`pip install pymysql openpyxl`) + Node(`npm i playwright`) → 解压 → `rewire.py --repair` → 填 `agent-secrets.json`（你的账号）→ 重开会话 → 验证四道。

## 第二步：建域层目录 + 填域配置（15 分钟）

1. 按 `agent-company.company-template.json` 复制为 `公司包/agent-company.json`：
   - **公司节已预填**（鲸天环境/端口/登录技能）——不用动；
   - **域节占位**——填你的值：`paths`（你的标准体系/用例文件/需求文档/台账四个目录）、`naming`（你的需求命名前缀，如“`{产品线}需求{YYYY}_`”）、`域词`（你的业务域一句话+造数前缀+分诊判据）、`白名单`（历史豁免，初始留空）；**可选键（如 ai_test）没有就留空字符串**——留空不做存在性检查，填了路径就必须真实存在。
2. 建四个目录（名字与 paths 一致）：
   ```
   你的工作区/
     需求文档/          ← 产品给你的需求 md 放这里
     用例文件/          ← 生成的用例正本/分章/报告落这里（自动生成）
     标准体系/          ← 你的域标准落这里（跑需求时自动抽离生长）
     需求流水线台账_v1.md ← 复制包内模板起步（或让 orchestrator 帮你建）
   ```

## 第三步：跑你的第一个需求（流水线全链路）

1. 把第一个需求文档放进 `需求文档/`，对 agent 说 **“熟悉下这个需求”** → 答疑一问一停（对话内文字拍板，禁选择框）；
2. 答疑闭环后 agent 出《澄清理解＋用例规划摘要》并停住 → 你说“开始生成”→ 生成 → 独立质疑 → 三格式交付；
3. 执行侧：说“执行{需求名}”→ agent 走执行框架（实例池/账本/批次计时/收尾校验全自动）；
4. 每轮收尾自动回写你的台账。**你的域数据从此自动生长**——第二个需求起，域标准/坑库/配方越滚越厚。

## 第四步：域层沉淀（随需求自动长，勿手工造）

| 沉淀 | 长在哪 | 机制 |
|---|---|---|
| 域标准（L4） | `标准体系/{菜单}_用例编写标准_v1.md` | qa-loop 答疑闭环后自动抽离 |
| 族标准（L2，如计费族） | 同上 | 同族第二个需求时归纳 |
| 执行坑（域册） | 你的执行目录 `执行坑库_v1.md` | 每轮执行收尾强制沉淀 |
| 接口 spec / Mock 模板 | `jt_exec 之外的你的执行目录` | 首测采集→沉淀→回归 |
| 弹窗/表单引擎 | 你的域执行目录 | 参考 `jt_exec/pw_layered/modules/_template.js` 包装 |

## 常见问题

- **凭证**：`agent-secrets.json` 唯一落点，永不出公司；token 一律运行时取，禁写死。
- **租户**：鲸天全产品线共用——切租户用登录技能（`jingtian-tenant-switch`），你的产品线用哪个租户问你们负责人。
- **执行实例**：`browser_pool` 独占制（持锁+心跳），禁直连固定端口与他人互踩。
- **造数**：`jt_exec/mock_push_template.py` 骨架 + 你的 Mock 接口文档字段表 = 你的造数模块（铁律四条见该文件头）。
- **门禁**：生成/执行双门禁、机检、收尾双校验全在公司层与技能里——对你是自动的，别绕。
