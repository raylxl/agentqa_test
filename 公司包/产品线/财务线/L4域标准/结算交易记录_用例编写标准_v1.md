# 结算交易记录 用例编写标准 v1

> **定位**：**结算交易记录域**的用例编写标准，**跨需求版本复用**——适用于「结算交易记录 8.11」及后续结算交易记录查询/导出优化需求；**不挂需求版本号**，需求版本级差异一律以该版本《需求理解说明》为唯一依据。
> **通用方法与归属正本**：《通用用例设计标准_v1》现行版及适用族标准《账单族标准_v1》；本文只管结算交易记录域的查询控件、多选匹配、权限过滤、导出与断言锚点。不复制通用正本内容，只引用；金额计算/报价匹配按账单族标准，本域变更未涉及。
> **抽离来源**：《财务需求2026_快运_结算交易记录_需求理解说明_v1》7 项拍板（Q1/Q2/Q2b/Q3/Q4/Q5/Q6，2026-11-23 全闭环，含独立完备性质疑补漏 Q6）。后续拍板新增按 v2 只增不覆盖。
> **消费方式**：结算交易记录用例分章生成时随章分发，子代理**不得重复询问、不得自创口径**；与通用正本/理解说明冲突时以理解说明为准；无覆盖 → "转测校准"句式 + 上报主流程，禁臆断。

## 一、固定枚举与控件常量（禁止自造取值）

| 项 | 常量 |
|---|---|
| 开户机构（查询控件） | 下拉**平铺清单**（非树形），每项 = 机构名称 + 机构编码；含「(已清算)」机构选项；**多选**、支持**模糊搜索**（名称/编码字段范围挂转测校准②）；**按机构编码端点精确匹配**，无"选中省公司含下级"层级语义（Q2） |
| 产品类型（查询控件） | 下拉**平铺清单**，每项 = **不带温层**的产品类型名称，无编码；示例鲸确达/鲸速达/鲸惠达/鲸小包/零担/小件/仓链干线/冷链快递；**多选**、支持模糊搜索（Q2） |
| 产品类型匹配值 | 按**产品类型主体（编码/主体值）**匹配，同主体下不同温层记录**全部命中**；下拉「冷链快递」与结果列「冷链快递达」为同主体不同展示层文案（Q2b） |
| 结果列产品类型 | **保留原值**（如「冷链快递达」），不随下拉去温层改文案；导出文件同口径（Q2b） |
| 多选组合语义 | 同字段多选取 OR、跨字段（交易时间/业务域/所属省份等）取 AND；不选择=不过滤、清空=恢复未选、搜索无结果保留已选项（转测校准①②，**未拍板，按推论执行+观察**） |
| 机构编码示例 | 010001/010002/010003 等均来自**用户设计稿**，不得当作真实主数据；执行期从快运真实机构主数据取有权/无权两组编码（转测校准⑦） |

## 二、业务对象常量表（含来源→本菜单呈现映射）

| 业务对象 | 来源/取值 | 本菜单呈现 | 现行出处 |
|---|---|---|---|
| 开户机构 | 账号机构权限过滤后的机构主数据（名称+编码） | 下拉平铺清单；选中编码端点作为查询条件 | Q2/Q4；KB 无本菜单直接卡（相邻域 RB-030/QA-2026-0029 仅侧证） |
| 产品类型 | 产品类型主体编码；温层为记录级属性 | 下拉显示去温层名称；结果列/导出显示原温层值 | Q2b |
| 结算交易记录 | 运单结算流水；账单族跨菜单断言锚点 | 结果列表 + 收入/支出汇总 + 导出文件 | 账单族标准 §账单侧菜单；本菜单无独立特殊规则 |
| 省公司收支 | 按机构多选聚合的收入/支出汇总 | 汇总行随筛选与权限过滤联动（是否跨页全量挂转测校准⑧） | Q3/Q5；转测校准⑧ |

**来源规则→呈现映射**：
| 规则 | 本菜单呈现 |
|---|---|
| 下拉产品类型去温层（Q2b） | 查询按主体匹配跨温层全命中；列表/导出仍显示各自原值；**禁写"下拉文案=列表文案"等式断言** |
| 账号机构权限（Q4/Q6） | 下拉清单、查询结果、导出文件三处同源按账号权限过滤；混入无权编码整单否决 |
| 已清算机构（转测校准③） | 仍在下拉选项中；选中后能否命中历史交易记录为执行期观察项，不臆断 |

## 三、结构常量（列/模块）

- **查询区**：开户机构（多选下拉）、产品类型（多选下拉）、交易时间/业务域/所属省份等原有条件；查询/重置/收起按钮。
- **结果区**：收入/支出汇总行 + 结果表（含运单号、机构编码、机构名称、产品类型原值、结算/计费重量等列，原型图为准，不臆造别名/列序）。
- **导出**：查询区「导出」按钮 → 现有异步导出任务链路。
- 本需求**不改**结果列结构与金额计算；仅查询控件改造与导出适配。

## 四、统一处理链路

账号权限确定可见机构 → 下拉清单仅列有权机构 → 用户多选机构/产品类型并模糊搜索 → 查询按「机构编码端点 OR（全有权时）/ 产品类型主体跨温层 / 跨字段 AND」过滤 → 列表与汇总呈现 → 导出取同一结果集全量跨页、同列同序生成异步任务文件。
越权路径：接口直调/篡改编码塞入无权机构 → 单项无权返 0 条；有权+无权混合 → **整单否决返 0 条**（Q6，OR 不适用）；导出同样过滤。

## 五、判定规则表（前置/预期直接引用）

### 5.1 控件与查询判定（Q2/Q2b）
| 场景 | 预期 | 断言 |
|---|---|---|
| 开户机构单选/多选 | 按选中机构编码端点匹配；多选为 OR | 选中机构记录命中，未选机构不命中 |
| 产品类型选中「冷链快递」 | 同主体下两个温层记录均命中 | 命中条数=两温层记录数之和；另一主体不命中 |
| 结果列产品类型 | 保留原温层值 | 列值=原值（如「冷链快递达」），**不做文案相等断言** |
| 模糊搜索 | 输入名称/编码片段命中对应项 | 命中项与片段一致；无结果显示空列表且保留已选（转测校准②观察） |
| 清空/不选 | 不按该字段过滤 | 结果=无该条件时的全集 |

### 5.2 权限判定（Q4/Q6 · P0）
| 场景 | 预期 | 断言 |
|---|---|---|
| 账号 A（有权 010001/010002）下拉 | 仅见 A 的有权机构 | 不含无权机构 010003 |
| 单项有权查询/导出 | 正常命中 | 结果/导出仅含该机构数据 |
| 单项无权（直调/篡改） | 0 条 | 无数据、无错误信息泄露机构存在性 |
| 混合 `[有权A, 无权B]` | ~~**整单否决 0 条**（查询与导出均 0）~~ → **B1 修正（2026-11-23 12:52）：剔除式降级**——忽略无权/无效编码，返回 A 的数据（机构集={A}，不含 B 记录，无泄露） | 断言改为：混合结果=有权子集且不含无权机构任何记录；不因混入无权放宽其余条件 |
| 导出文件 | 仅含有权机构数据 | 不含 B 的记录；字段按原型原值不脱敏 |

### 5.3 导出判定（Q5）
- 导出**当前筛选结果集全量（跨页）**，非当前页；行数=结果集条数，按运单号/账单编号集合一一对应。
- 导出列与列表**同列同序**；产品类型列保留结果列原值；收入/支出汇总与页面一致。
- 沿用现有异步导出任务；任务页下载工具链不可用时按执行标准记合法 BLOCKED，禁伪造 PASS（转测校准⑥）。

### 5.4 可靠性/可用性判定（Q1 + 转测校准）
- 多选无命中、全选、已清算机构、空结果集行为按转测校准③⑤观察，不臆断为肯定断言。
- 性能/容量轻量测：观测样本量与耗时，不做硬指标断言。

## 六、断言锚点口径（结算交易记录域）

| 断言对象 | 标准句式 |
|---|---|
| 开户机构多选 | 选中编码端点集合命中对应机构记录；未选机构不命中 |
| 产品类型跨温层 | 选「冷链快递」→ 命中同主体全部温层记录；结果列各显原值；禁"下拉文案=列表文案" |
| 权限三处同源 | 下拉可见性/查询结果/导出文件三处均为账号有权机构子集；无权机构不出现 |
| 混合请求 |  `[有权A, 无权B]` → 查询 0 条 + 导出 0 条；`[有权A]` → 正常 |
| 导出 | 结果集全量跨页、同列同序、集合与行数一致、汇总一致 |
| 脱敏 | 字段按原型原值展示，不做掩码断言（Q4） |

## 七、转测校准清单（**不得写成肯定式断言**，用"转测校准：观察…"句式）

①同字段 OR / 跨字段 AND（Q6 后限定：仅限全部编码有权，混入无权整单否决优先）；②模糊搜索字段范围（机构名称/编码、产品类型名称，大小写/空格敏感）；③已清算机构能否命中历史记录；④产品类型主体与结果列温层值实际映射（抽样核对同主体多温层是否都被选中）；⑤空结果集时导出行为（提示/仅表头文件/按钮置灰）；⑥异步导出下载工具链可用性（不可用按合法 BLOCKED 登记）；⑦越权用例机构编码取自真实主数据，非设计稿 010001/010003；⑧收入/支出汇总为筛选后全量还是当前页。

## 八、数据准备（PRE）依赖清单（造数配置项，不归属用例、不计数）

| 类 | 需备数据 |
|---|---|
| 机构权限 | 快运租户内两个机构权限不同的账号（有权/无权各至少 1 组真实编码），记录取值来源（转测校准⑦） |
| 跨温层 | 同一产品类型主体下两个温层的结算交易记录 + 另一产品类型记录 |
| 多选组合 | 跨 2 个机构（最好跨省公司）+ 结果集跨 2 页的数据；含时间/省份条件以验跨字段 AND |
| 已清算/空值 | 已清算机构历史记录、无命中组合、空结果集（转测校准③⑤） |
| 导出 | 可触发异步导出任务的账号与环境；产物用于集合/列序/汇总比对 |
