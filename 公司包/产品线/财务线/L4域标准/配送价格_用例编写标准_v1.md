# 配送价格 用例编写标准 v1

> 菜单：财务→配送价格（云仓三类报价之三，版本 11.30）。依据=《财务需求2026_云仓_配送价格_10.？_需求理解说明_v1.md》（Q1~Q20 拍板闭环）与《通用用例设计标准_v1》与适用族标准（报价政策族/计费专项；冲突时以所引正本为准，体系见 00_标准体系索引）。跨版本复用；只新增不修改。

## 一、固定枚举与控件常量（禁止自造取值）

> **归属边界（2026-11-11）**：配送域源规则（费用项、目的地/8维匹配、公式、精度和自提例外）由本域持有；通用报价/政策机制引用 L2《报价政策族标准》，计费专项引用 L2《计费专项标准》，账单载体映射引用 L2《账单族标准》。本域的账单落点描述保留为消费侧用例指引，不构成账单菜单的第二份规则正本。单仓共用判据引用 L3 §2.8，本域只判配送费用的域内结果。

| 字段 | 取值 |
| --- | --- |
| 费用名称 | 快递费、配送费 |
| 结算流向 | 总部收业务仓、总部付操作仓（"总部收操作仓"=源文档笔误禁用） |
| 计费维度 | 重量、出库箱数（SKU实件=产品笔误禁用） |
| 重量精度 | 实际值(默认)、0.1进位、0.5进位、向上取整 |
| 费用精度 | 分(默认)、角、元 |
| 生效日期默认 | 次日；失效日期初始=空待选择 |
| 数值域 | 主单 0-999999 两位小数；子单 0-999999 四位；首重/基础箱数/箱数整数；适用重量/单箱重量两位 0-999999.99；其余 0-999999 |
| 段上限 | 重量段/单箱重量档/箱数段统一 ≤4；目的地无上限 |
| 模板 | 出库箱数版必填 13 项（11+单箱起止）、重量版 12 项（11+重量段起止）；计价组 4 组列（源需求 6 组=笔误） |

## 二、两费项常量表

| 费用项 | 维度 | 明细公式 | 主子单 |
| --- | --- | --- | --- |
| 快递费 | 重量 | 首价+(W′−首重)×续价→夹取 | ✗ |
| 快递费 | 出库箱数 | 基础价格+max(0,N−基础箱数)×续价→段级夹取→Σ | ✗ |〔2026-11-25 W3 修订→见 §十〕
| 配送费 | 出库箱数 | 同上 | ✓ |〔2026-11-25 W3 修订→见 §十〕
| 配送费 | 重量 | 同① | ✓ |

- 主子单归属=费用名称（配送费可配，与维度无关）；子单数量=出库箱数（w=0 箱计入）；重量维度子单数量口径=转测校准。
- 进位族：向上进至最近倍数（0.5/0.1/整数，已是倍数不变）；重量精度作用匹配段前、费用精度最终金额后一次 half-up。
- 事件：订单处理（首次生成）+出库完成（重算覆盖）；自提=双费项豁免。

## 三、列结构常量

列表 22 业务列（报价编码…审核时间）；导出=列表∪模板列、原值不补零、无数据=仅表头空文件；账单落点：收向→业务仓账单（支出）仓付/总部收、付向→操作仓账单（收入）总部付/仓收。

## 四、统一匹配链路

云仓造单（客户/业务仓/操作仓/物流公司/产品/账号/目的地/结算重量/出库箱数×单箱重量）→订单处理→出库完成重算→按单号查账单+结算交易记录（双断言）。硬条件：费用名称/流向/物流公司/两精度/维度/区间；排序 8 维全序（客户>业务仓>操作仓>物流账号>物流产品>区县>城市>省份，每维精确>空，精确≠订单值→整报价排除）；状态只匹配已审核（未审/驳回/副本期间不参与，各出专条禁常量前置）。
