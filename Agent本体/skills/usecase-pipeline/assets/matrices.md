## 表二 · 操作时序对矩阵（有金额账本的菜单必做）

操作集示例：重算 / 取消 / 重量修正 / 出库完成 / 拦截 / 报价变更。两两 × **双向先后**，断言"后操作以前操作结果为基准"。

| 先 → 后 | 断言要点 | 归属章 |
| --- | --- | --- |
| 重算 → 取消 | 对冲流水金额=重算后金额（非原始） | 已取消章 |
| 取消 → 重算 | 金额保持空（已取消节点无费用） | 重算章 |
| 重量修正 → 取消 | 对冲最新金额 | 已取消章 |
| 重算 → 出库完成 | 出库事件按最新订单信息重匹配，重算结果不锁死 | 事件流章 |
| 出库完成 → 重算 | 两侧均重算 | 重算章 |
| 报价变更 → 重算 | 按新报价重匹配，红冲重结/只更新按费用项状态 | 重算章 |

填写法：n 个操作 → n×(n−1) 个有向对，逐对判"是否有可观测差异"；无差异写"同向等价"也要留痕，证明想过。

## 表三 · 越权路径清单（数据权限章）

每条路径一条"权限外不可达"，不只测列表默认过滤。

| 越权路径 | 断言 | 归属章 |
| --- | --- | --- |
| 列表默认过滤 | 权限外行不出现 | 权限章 |
| 精确单号直查 | 权限外单号查询无结果（对照总部可查） | 权限章 |
| 条件查询交集 | 结果=条件命中 ∩ 权限范围 | 权限章 |
| 导出 | 文件不含权限外行/无权限金额格空 | 导出章或权限章 |
| 接口直调 | 非授权 token 直调查询/操作接口被拦 | 权限章 |
| 详情/弹窗直链 | 权限外数据详情不可达 | 权限章 |
| 按钮权限配置 | 查询/重算/导出等按钮纳入角色配置（观察类） | 权限章 |

## 使用约定

- 三表随 BRIEF 一起产出，"归属章"写进该章覆盖要求；子代理不得自判"归别章"。
- 生成后由门禁 A 按表逐格回填"落位 TC"，空格=缺口。
- 操作集按该菜单实际功能按钮列（账单/报价/政策类不同）。
