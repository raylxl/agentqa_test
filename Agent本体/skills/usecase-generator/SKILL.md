## 1. BRIEF 组装与三矩阵前置

1. 读 `../usecase-pipeline/references/brief-and-prompts.md` 填入本需求路径作为子代理公共段；**必须内嵌进每个 prompt，只给路径＝未分发**（必嵌：条目格式与优先级体系、执行设计纪律、方法选择与覆盖矩阵、族/专项标准按需引用、判重和风险—覆盖深度/NFR矩阵、可执行写法边界——正本章节清单由 {standards} 解析，降级=通用包 §1/§2/§6.2/§11）。避免把历史方法矩阵或旧 P0/P1/P2 映射当现行口径。
1a. **策略卡先行**：BRIEF 首行必须写入口档位、关键风险、P0/P1/P2/P3预估、全谱系测/不测理由、执行集、入口/出口条件；没有策略卡和风险—覆盖深度矩阵不得派发分章代理。
2. 章节规划：按理解说明"用例规划"落章；每章定章号/章名/TC 前缀/章码/业务日期窗（按章错峰）/目标条数区间/覆盖要求（列到拍板编号+与相邻章分工边界）。
3. **章节指派对账表**（§9-1a）：逐功能点对账"已落位到章 X"，**无落位禁派发**。
4. **三矩阵前置**（`../usecase-pipeline/assets/matrices.md`）：口径交叉表/操作时序对/越权路径清单，逐格指定归属章并写进该章覆盖要求。
5. 造数隔离：业务对象前缀按 {域词.造数前缀}（降级默认 OBJ{章码}），各对象名＝前缀+章码+序号；日期窗按章错峰。
6. **接口章前置扒卡（2026-11-17 接线，公司层 `integrations.knowledge_base`）**：BRIEF 组装时对 `API-` 接口章按接口名/服务名查开发知识库（`{paths.公司包}/tools/wk_kb.py search "<接口名/服务名>"`）——IF 卡的**入参字段枚举／L2·L3 断言语汇／易混接口辨析**作为该章 prompt 素材注入（子代理禁自行检索，KB 结论经 BRIEF 分发）；判断依据可引用卡编号（如 IF-waybill-send-bill）。IF 卡缺失/存疑→**直读 Controller/DTO**（`integrations.dev_git`——字段/类型/必填/校验注解以代码为最终契约，引用带`仓:分支:类:行号`）；两源均无→按需求文档＋流量首录走，记 BLOCKED 不阻塞。

## 2. 分章生成（子代理并行）

**每批 ≤8 章**（批内同消息并发、整批返回再发下一批；15+ 章一次并发撞 1302 限流实测 48min，8+7 分批约 28min）。约束：只许 Read 理解说明与域标准、**禁读其他用例文件**；Write 到 `{paths.用例文件}\{naming.分章目录模式}\NN_前缀.md`；只回报统计不贴正文。撞限章合并 ≤4 章小批重发。全批完成后抽读一份确认横表格式；格式跑偏用 SendMessage 让该章代理就地整改，主流程不手改。

## 3. 组装与结构门禁（脚本）

```bash
# 竖排：pipeline 自带
python ../usecase-pipeline/scripts/assemble.py --dir "<分章目录>" --check-only
python ../usecase-pipeline/scripts/assemble.py --dir "<分章目录>" --out "<成册md>" --title "..." \
  --intro-file 导语.md --pre-file PRE.md --footer-file 修改记录.md
```

结构门禁＝重号/断号/表结构/判断依据/计数自洽等，全零才全绿；编号字母集、历史豁免和组装入口从公司 profile 解析。**承载条铁则**：TC-SYS/TC-DEF/TC-IMP/TC-CHG 块判断依据必须挂`老用例编号：`或`原用例无对应：…`（assemble.py 机器拦；**初版册的系统守护条同样适用**，标『原用例无对应：初版系统守护条』）；正本=《{standards.L6_闭环}》§二-2（2026-11-19 真机：规则原只在闭环标准的修订场景述，generator 侧未述，门禁红了"不明所以"）。**治理正本＝治理 JSON**（风险—TC/执行集/P0123/阶段 readiness 由校验器硬门；策略卡是派生视图；设计/验证阶段允许 awaiting_environment，执行阶段必须 ready）。

**双源同步纪律（铁则）**：①**分章＝唯一源**——任何直改成册的改动下一次重组装即被冲掉，改用例必改分章；②**重组装后必须核对总条数**，与预期不符立即停并比对；③组装违例写 `.draft` 不覆盖正本（正本＝上版全绿的免费备份）。

## 4. 产出移交（→ usecase-challenger）

移交三样：①成册初稿（＋分章目录路径）②BRIEF 公共段全文＋章节规划 ③三矩阵（含逐格归属）。移交后**禁再自行改动**；质疑方违例清单回来后在**分章源**上当轮根治、重组装、复审总条数。
