# 测试报告三段式模板 v1.0

> **一份报告原则**：全部执行批次并入一份报告，禁按轮次/批次出版多份。骨架三段冻结，轮次块只增不回改。
> 配套标准：《AI 自动化测试用例编写标准_通用版》§12（四态与纪律）、§13（执行出口尺）。

---

# 一、总进度（置顶，每轮必更）

## 1.1 状态一句话
> 当前状态（进行中/已收官）+ 置信度判断（"可以/不可以进入下一阶段，依据是…"）+ 出口判定（§13 执行出口尺逐项 ✓/✗）。

## 1.2 四态统计
| 优先级 | 总数 | PASS | FAIL | NOT_EXECUTED | BLOCKED | 通过率 | 环比上轮 |
|---|---|---|---|---|---|---|---|
| P0 | | | | | | | |
| P1 | | | | | | | |
| P2/P3 | | | | | | | |

## 1.3 模块全景
| 模块/功能域 | 用例数 | 通过 | 失败 | 未执行 | 阻塞 | 状态 |
|---|---|---|---|---|---|---|

## 1.4 余量摘要（每轮必更）
剩余未执行/待复验/待定夺项，每条带负责人与预计处置。

---

# 二、执行轮次（每轮一块，只增不回改）

## 第 N 轮（日期）
| 字段 | 内容 |
|---|---|
| 环境 | 环境/地址（凭证不落报告）+ 就绪检查结论 |
| 范围 | 本轮执行的用例集（编号区间/筛选条件）与数量 |
| 结果 | 四态统计 + 与上轮环比 |
| 失败清单 | 每条 FAIL：用例号/步骤/预期/实际/证据链接/初判分流 |
| 阻塞清单 | 每条 BLOCKED：原因/处置/是否复跑 |
| 缺陷变化 | 新建缺陷单号/关闭单号/回归状态 |
| 口径变化 | 本轮定夺的口径（引用确认记录编号） |
| 系统实现发现 | 实现行为与文档不符处的记录（四源候选） |
| 用例问题 | 用例自身错误（写错预期/不可执行）及修正 |
| 覆盖度 | 已执行/总数/需求覆盖率/风险覆盖率 |
| 证据 | 执行记录/截图/日志的工件索引（Execution ID） |

---

# 三、支撑数据（附录）

## A1 环境就绪
环境清单、账号来源（不落凭证）、数据准备与清理记录。

## A2 失败与失效详说
- 每条 FAIL 的完整五段呈报与定夺结果；
- 用例册演进账本：原设计 N 条 → SYS/DEF/IMP/CHG 增量各 M 条 → 失效 K 条 → 现有效可执行合计。

## A3 工件与沉淀索引
报告/用例册/证书/脚本/执行账本的文件位置与版本。

## A4 余项清单（每轮必更）
挂起项、待复验项、转观察项——每条带触发条件。

## A5 呈报-定夺台账（只增）
| 日期 | 事项 | 呈报轮 | 定夺 | 落实状态 |
|---|---|---|---|---|
