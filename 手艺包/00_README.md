# 通用测试 agent 包（手艺包）

> 一套**行业无关**的 AI 测试方法论资产包：任何行业的测试人员拿到后，配上自己公司的信息即可跑通"需求澄清 → 用例设计 → 独立质疑 → 执行 → 报告 → 反馈回写"整条链。
> 本包不含任何公司系统、数据与凭证（每次发版过机检：内置硬规则=零绝对路径/零内网IP/零明文凭证/零词表命中，另有邮箱与 git 元数据检查；中文业务域词需自配词表才检查——发版前建议配置）。

## 快速上手（三层任选）

1. **只看文档**：读 `01_标准/` 两份标准，按标准改写你的用例；拿 `02_提示词与模板/` 三件提示词直接投喂你在用的 AI 工具。
2. **接你的 agent**：把 `02_` 的模板作为你的 agent 的固定工作格式（BRIEF 开工、五段式提问/呈报、三段式报告收尾）；`03_` 机检接进你的交付流程当门禁。
3. **公司接入**：复制 `03_检查脚本/wordlist.example.json` 为你的公司词表（**放在本包目录之外**——词表属你的私有数据），填入你们的公司/系统专名与内网域名，发版前 `python generic_layer_check.py <包目录> --config <你的词表>` 全绿才放行。

## 核心理念（一页懂）

- **通用层 + 领域扩展**：标准正文只有方法论；你们系统的行为口径、设计规则放"领域扩展文件"（A 类行为断言基线库 / B 类领域设计规则库）挂载，通用层永不混入业务数据（标准 §8）。
- **双门禁**：生成方不自证——设计走"生成 vs 独立质疑"，执行走"生产 vs 独立质检"（标准 §6.6）。
- **四态与出口尺**：PASS/FAIL/NOT_EXECUTED/BLOCKED 四态记账，P0=100% 等量化出口全绿才出报告（标准 §12/§13）。
- **四源回写**：执行完主动盘点 SYS/DEF/IMP/CHG 四类变化，负责人定夺后落册，原正文不动、增量承载（标准 §14）。
